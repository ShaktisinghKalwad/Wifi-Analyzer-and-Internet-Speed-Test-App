## 📶 WiFi Analyzer & Internet Speed Test App
A modern Android application that helps users analyze nearby WiFi networks and measure real-time internet speed including download, upload, and ping.
Built for performance, simplicity, and accurate network diagnostics.

## 🚀 Features
✅ Scan nearby WiFi networks
✅ Signal strength visualization
✅ Channel & frequency detection
✅ Internet speed test (Download / Upload / Ping)
✅ Network security type info
✅ Clean & fast UI
✅ Lightweight & battery optimized

## 🛠 Tech Stack
-Android (Kotlin / Java)
-WiFi & Network APIs
-Real-time speed measurement logic
-Material UI Components

## 📊 How It Works
WiFi Analyzer
--Scans available networks
--Reads signal strength (dBm)
--Shows channels and frequency
--Displays security protocols

Speed Test
--Measures real-time download speed
--Measures upload speed
--Calculates ping latency
